# Elman-Jordan Recurrent Neural Network (Java)

Реализация рекуррентной нейронной сети (РНС) архитектуры Элмана-Джордана на языке Java. Проект предназначен для прогнозирования временных рядов и числовых последовательностей.

Выполнено в рамках Лабораторной работы №3 по дисциплине МРЗвИС.

## 📋 Требования

*   **Java 17** или выше.
*   **Maven** (для сборки проекта).

## 🛠 Сборка проекта

Находясь в корневой папке проекта (где лежит `pom.xml`), выполните команду:

```bash
mvn clean package
```

После успешной сборки скомпилированный JAR-файл появится в папке `target/` (например, `elman-jordan-rnn-1.0-SNAPSHOT.jar`).

## 🚀 Запуск

Базовая команда для запуска:

```bash
java -cp target/elman-jordan-rnn-1.0-SNAPSHOT.jar by.bsuir.lab3.Main [АРГУМЕНТЫ]
```

### Доступные аргументы

| Флаг             | Значение по умолчанию | Описание                                                                 |
|------------------|-----------------------|--------------------------------------------------------------------------|
| `--seq`          | `fib`                 | Имя последовательности (`fib`, `geom`, `per1`, `per2`, `nat`, `sqr`, `fact`). |
| `--seq-len`      | `10`                  | Длина обучающей выборки.                                                 |
| `--predict-len`  | `10`                  | Количество шагов для предсказания.                                       |
| `--win-len`      | `2`                   | Размер скользящего окна (количество входов).                             |
| `--hidden`       | `15`                  | Количество нейронов в скрытом слое.                                      |
| `--con-len`      | `5`                   | Размер контекстного слоя (памяти).                                       |
| `--eff-len`      | `3`                   | Размер эффекторного слоя (обратная связь от выхода).                     |
| `--alpha`        | `0.00008`             | Скорость обучения (Learning Rate).                                       |
| `--iters`        | `500000`              | Максимальное количество итераций обучения.                               |
| `--max-error`    | `1e-5`                | Целевая ошибка обучения (MSE).                                           |
| `--log`          | *нет*                 | Использовать логарифмирование данных (для экспоненциальных рядов).       |
| `--zscore`       | *нет*                 | Использовать Z-score нормализацию (стандартизация).                      |
| `--no-reset-ctx` | *нет*                 | Не сбрасывать контекст между эпохами (сохранять "мысли" с прошлой итерации). |

## 📚 Справочник последовательностей и стратегии запуска

В программе предусмотрено 9 типов последовательностей. Нейросеть требует разного подхода к каждой из них в зависимости от того, растут ли значения, убывают или повторяются.

### 1. Быстрорастущие (Экспоненциальные и Факториальные)
*Значения улетают в бесконечность очень быстро. Без логарифмирования сеть не справится из-за переполнения и взрыва градиентов.*

| Код | Название | Пример | Стратегия |
|---|---|---|---|
| `fib` | **Фибоначчи** | `0, 1, 1, 2, 3, 5, 8...` | Обязательно `--log`. |
| `fib-like` | **Подобная Фибоначчи** | `1, 2, 3, 5, 8, 13...` | Обязательно `--log`. |
| `fact` | **Факториалы** | `1, 2, 6, 24, 120...` | Обязательно `--log`. Рост даже быстрее, чем у Фибоначчи. |

**Рекомендуемый запуск:**
```bash
java -cp target/elman-jordan-rnn-1.0-SNAPSHOT.jar by.bsuir.lab3.Main --seq fib --log --alpha 0.0001
```

---

### 2. Полиномиальные и Линейные (Монотонный рост)
*Растут бесконечно, но медленнее экспоненты. Основная проблема — экстраполяция (предсказание значений, которые больше тех, что были в обучении).*

| Код | Название | Пример | Стратегия |
|---|---|---|---|
| `sqr` | **Квадраты** | `1, 4, 9, 16, 25...` | Желательно `--log`. Функция $log(x^2)$ превращается в $2 \cdot log(x)$, что проще для сети. |
| `nat` | **Натуральные** | `1, 2, 3, 4, 5...` | Можно без нормализации, но с маленьким `--alpha`. Z-score может исказить тренд при экстраполяции. |

**Рекомендуемый запуск (Квадраты):**
```bash
java -cp target/elman-jordan-rnn-1.0-SNAPSHOT.jar by.bsuir.lab3.Main --seq sqr --log --alpha 0.0001
```
**Рекомендуемый запуск (Натуральные):**
```bash
java -cp target/elman-jordan-rnn-1.0-SNAPSHOT.jar by.bsuir.lab3.Main --seq nat --alpha 0.00001 --iters 600000
```

---

### 3. Периодические (Повторяющиеся паттерны)
*Значения колеблются в ограниченном диапазоне. Самый важный параметр здесь — размер окна (`--win-len`), он должен быть не меньше длины периода повторения.*

| Код | Название | Пример | Период | Стратегия |
|---|---|---|---|---|
| `per1` | **Колебания** | `0, -1, 0, 1...` | **4** | `--win-len 4`. Z-score помогает выровнять амплитуду. |
| `per2` | **Бинарный паттерн** | `0, 1, 0, 0, 1, 0...` | **3** | `--win-len 3` (или 4). |

**Рекомендуемый запуск (per1):**
```bash
java -cp target/elman-jordan-rnn-1.0-SNAPSHOT.jar by.bsuir.lab3.Main --seq per1 --win-len 4 --zscore --alpha 0.001
```
**Рекомендуемый запуск (per2):**
```bash
java -cp target/elman-jordan-rnn-1.0-SNAPSHOT.jar by.bsuir.lab3.Main --seq per2 --win-len 3 --alpha 0.001
```

---

### 4. Убывающие (Сходящиеся к нулю)
*Значения становятся очень маленькими. Без нормализации градиенты исчезнут (станут нулями), и сеть перестанет учиться.*

| Код | Название | Пример | Стратегия |
|---|---|---|---|
| `geom` | **Геометрическая** | `0.5, 0.25, 0.125...` | Обязательно `--zscore`. |
| `recip` | **Обратные числа** | `0.5, 0.33, 0.25...` | Обязательно `--zscore`. |

**Рекомендуемый запуск:**
```bash
java -cp target/elman-jordan-rnn-1.0-SNAPSHOT.jar by.bsuir.lab3.Main --seq geom --zscore --alpha 0.0005
```

---

### Сводная таблица параметров

| Последовательность | Флаг `--seq` | `--log` | `--zscore` | `--win-len` (рек.) | Примечание |
| :--- | :--- | :---: | :---: | :---: | :--- |
| Фибоначчи | `fib` | ✅ | ❌ | 2-3 | Экспоненциальный рост |
| Геометрическая | `geom` | ❌ | ✅ | 2 | Стремится к 0 |
| Обратные числа | `recip` | ❌ | ✅ | 2 | Медленно стремится к 0 |
| Периодическая 1 | `per1` | ❌ | ✅ | **4** | Период 4 шага |
| Периодическая 2 | `per2` | ❌ | ❌ | **3** | Сложный ритм |
| Натуральные | `nat` | ❌ | ❌ | 2-3 | Линейный рост |
| Квадраты | `sqr` | ✅ | ❌ | 2-3 | Полиномиальный рост |
| Факториалы | `fact` | ✅ | ❌ | 2-3 | Взрывной рост |
