# unv-sem7
## Написать 3 примера фрагментов кода языка по варианту, все свойства должны быть использованы, встроенные типы, операции и функции должны быть использованы и показаны на примерах
## Свойства:
- объявление переменных — явное
- преобразование типов — неявное
- оператор присваивания — одноцелевой (a = b)
- структуры, ограничивающие область видимости — подпрограммы
- маркер блочного оператора — явные { } или begin end
- условные операторы — if-then-else и switch-case
- перегрузки подпрограмм — нет
- параметры — только по значению / возвращаемому значению
- место объявления подпрограмм — в начале программы
## Целевой код: байт-код .NET (CIL).
